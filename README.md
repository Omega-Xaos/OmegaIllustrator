# Omega Illustrator

Локальный SVG-редактор для создания иллюстративных композиций из подготовленного каталога векторных объектов. AI-провайдер предлагает проверяемый JSON-план, а приложение размещает исходные SVG и позволяет вручную править сцену.

> **Демо-релиз для оценки, не production-сервис.** ChatGPT OAuth здесь оставлен для добровольной локальной проверки на собственном аккаунте. Это не OpenAI API-ключ и не отдельный пул запросов: при согласии в браузере тест расходует доступный лимит аккаунта. Не используйте план ChatGPT как производственный API, не объединяйте и не перепродавайте лимиты. Для production используйте API провайдера с отдельной оплатой. Коммерческое или удалённое использование ChatGPT plan требует отдельной проверки и допуска по актуальной программе OpenAI Sign in with ChatGPT.

## Быстрая проверка без Visual Studio

Скачайте Windows x64 сборку из [GitHub Releases](https://github.com/Omega-Xaos/OmegaIllustrator/releases/latest), распакуйте ZIP и запустите `Start-OmegaIllustrator.cmd`. Приложение включает .NET Runtime; Visual Studio и отдельная установка .NET не требуются. Затем откройте `http://127.0.0.1:5190`.

Чтобы проверить работу без расходов на AI, соберите сцену в режиме **По объектам**. Чтобы проверить модель, откройте **Подключение ИИ** (`/ai`), выберите локальное демо-подключение ChatGPT OAuth либо создайте API-профиль своего провайдера. OAuth появится только если текущий аккаунт и OpenAI flow разрешат такой доступ; доступность и лимиты не гарантируются. После подключения выберите модель и проверьте, что статус сообщает об ответе модели, а не об offline fallback.

Подробные шаги, настройки OpenRouter / OpenAI API / Anthropic / Gemini / локального API, ошибки и сборка исходников: [руководство запуска и проверки](docs/SETUP_AND_DELIVERY.md). Фактические тесты и ограничения: [проверки](docs/TESTING.md); ZIP-отчёт приложен к Release.

## Что внутри

- .NET 10 веб-приложение для ручного редактора и сборки композиций.
- Отдельная небольшая .NET-библиотека `Omega.AI.Gateway` с общим контрактом и адаптерами провайдеров; это вспомогательный компонент проекта, не заявление о поддержке любого AI API.
- Каталог подготовленных SVG, палитры, примеры сцен и валидация JSON-плана до применения.
- Офлайн-подбор на случай недоступности AI-провайдера.
- Самостоятельная Windows x64 сборка в Release и исходники в двух Git-репозиториях.

## Сборка исходников

Для исходников нужен .NET 10 SDK, Visual Studio не требуется. Клонируйте приложение и вспомогательную библиотеку в соседние папки с указанными именами, затем запустите тесты:

```powershell
git clone https://github.com/Omega-Xaos/OmegaIllustrator.git SVG_Auto
git clone https://github.com/Omega-Xaos/Omega-AI-Gateway.git DLL_OMEGA_LAB_CONNECT_AI
cd SVG_Auto
dotnet test .\OmegaIllustrator.slnx -c Release
```

Публикация самостоятельной Windows x64 сборки:

```powershell
dotnet publish .\src\OmegaIllustrator.Web\OmegaIllustrator.Web.csproj -c Release -r win-x64 --self-contained true -o .\publish\win-x64
```

См. [сборочные и API инструкции](docs/SETUP_AND_DELIVERY.md). API-ключи, ChatGPT-токены, локальные настройки и пользовательские композиции в репозиторий и Release не входят.

## Границы поставки

- Это локальный однопользовательский редактор, работающий на loopback. Публичное размещение и сетевой доступ из этой сборки не поддерживаются.
- ChatGPT OAuth оставлен для демонстрации на собственном аккаунте; он подчиняется consent-экрану, доступности и лимитам OpenAI. Для производственного использования в этом проекте этот путь выключен как неподдерживаемый бизнес-тариф. OpenAI отдельно описывает Sign in with ChatGPT для локальных open-source приложений и отдельные условия для коммерческих/удалённых интеграций.
- API-профили используют ключи, добавленные самим владельцем в `/ai`. ChatGPT Plus не включает обычные API-вызовы: биллинг ChatGPT и API Platform раздельный.
- Локальный Codex CLI/app-server не подключён. Вход ChatGPT OAuth и использование Codex как отдельного agent runtime — разные интеграции.
- Доступность моделей, бесплатная квота и успешность генерации зависят от стороннего провайдера. Валидация неудачного AI-плана включает offline fallback.
- До публичной публикации нужно проверить права на исходные SVG. Сейчас репозитории предназначены для приватного обзора работодателем.

Ссылки на официальные правила: [использование ChatGPT plan в приложениях](https://help.openai.com/en/articles/20001542-using-your-chatgpt-plan-in-other-apps-and-sites), [раздельный биллинг ChatGPT и API](https://help.openai.com/en/articles/9039756-managing-billing-for-chatgpt-and-the-api-platform), [Sign in with ChatGPT для локальных open-source приложений](https://developers.openai.com/siwc/token-sharing-open-source).
