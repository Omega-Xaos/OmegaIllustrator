# AI-подключения и использованные инструменты

## Провайдеры в приложении

Настройка находится на странице **Подключение ИИ** (`/ai`). Поддерживаются:

- официальный поток ChatGPT OAuth, если он доступен конкретному аккаунту и среде;
- OpenAI-compatible API — в том числе OpenRouter и локальные серверы, реализующие совместимый формат;
- Anthropic Messages API;
- Google Gemini API.

Добавьте профиль, укажите протокол, базовый URL, параметры ключа и сохраните его. Затем выберите профиль, нажмите проверку соединения/загрузку моделей и выберите одну из моделей, которую вернул именно этот сервис. Поддержка формата не означает, что любой URL или модель совместимы со всеми функциями приложения.

Ключ хранится серверной частью в защищённом виде и не включается в экспорт композиции. После сохранения поле ключа намеренно не показывает сохранённое значение. Не используйте бесплатную квоту как гарантию доступности: ограничения, 401/429, доступ к моделям и цены задаёт провайдер.

## Назначение модели

Модель возвращает JSON-план объектов и отношений. Приложение проверяет план по локальному каталогу, применяет правила размеров/слоёв/палитры и само строит SVG. При ошибке запроса применяется локальный смысловой fallback. Полная спецификация промта и JSON-контракта: [COMPOSITION_MODEL.md](COMPOSITION_MODEL.md).

## Codex

Текущая сборка не запускает локальный Codex CLI/app-server и не использует Codex как профиль провайдера. Codex — отдельный агентный runtime, а не OpenAI-compatible HTTP endpoint. Для генерации сцен используйте ChatGPT OAuth (если доступен аккаунту) или API-профиль поддерживаемого протокола. Инструкции и граница текущей поставки: [руководство запуска и передачи](SETUP_AND_DELIVERY.md#chatgpt-oauth-и-codex--это-разные-подключения).

## Инструменты разработки

- OpenAI Codex использовался как помощник разработки и проверки кода.
- .NET SDK 10 и `dotnet test`/`dotnet publish` использованы для сборки и локальной проверки.
- Для извлечения графики использованы предоставленный файл Figma `.fig` и локальный `FigmaAssetExtractor`; веб-авторизация Figma не применялась.
- Во время локальной проверки OpenRouter список моделей и запрос композиции завершились HTTP 200. Это подтверждает конкретный локальный прогон, а не постоянную доступность провайдера.
