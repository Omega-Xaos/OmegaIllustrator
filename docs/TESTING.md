Локальный HTTP smoke запускает только loopback без HTTPS; ASP.NET Core пишет предупреждение, что порт для HTTPS-перенаправления не задан. Оно не мешает локальному ответу 200. Пакет не должен выставляться в локальную сеть или интернет как публичный сервер.

Формальная проверка визуального совпадения всех 40 векторов наложением на исходные узлы Figma, тест во всех браузерах/на чистом компьютере и импорт каждого экспорта в Figma этой локальной проверкой не выполнялись.
