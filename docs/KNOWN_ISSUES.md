# Известные ограничения перед передачей

- XML-аудит гарантирует корректную структуру и отсутствие растровых/внешних зависимостей в 40 runtime SVG, но не доказывает попиксельное совпадение всех 40 вариантов с Figma. Каталог происхождения сам помечает сплошное визуальное сравнение как незавершённое.
- AI-провайдер может вернуть ошибку, ограничить бесплатные запросы или дать план, который не проходит валидацию. UI использует локальные правила вместо неподтверждённого плана; для теста провайдера нужен собственный доступ/квота.
- Локальная сборка слушает HTTP только на loopback; middleware HTTPS-перенаправления сообщает предупреждение, если HTTPS endpoint не настроен. В этой поставке удалённый доступ не настраивается.
- Состав доступных моделей загружается у конкретного сервиса. Список может меняться, а разные модели могут по-разному соблюдать структурированный JSON-контракт.
- Интеграция локального Codex CLI/app-server в текущую сборку не входит. ChatGPT OAuth в настройках Omega Illustrator — отдельный способ входа и не подключает процесс Codex.
- Пакет готовится только для Windows x64. Другие ОС не проверялись.
- Архив предназначен для локальной демонстрации. Публичное многопользовательское развёртывание с пользовательскими API endpoint/key не входит в данную поставку; для сервера нужны аутентификация, ограничение доступа, защита SSRF и отдельное управление ключами.
- Аккаунт/секреты и данные из `%LOCALAPPDATA%\OmegaIllustrator` в архив не включаются. После распаковки профиль провайдера на другом ПК необходимо настроить заново.
