# Демонстрационные сценарии

В `examples/` лежат готовые редактируемые SVG-композиции и машинно-читаемые планы. Они собраны из оригинальных векторных элементов каталога и предназначены для демонстрации ролей, палитр, масштабов и перекрытий; это не сохранённые ответы конкретной AI-модели.

| Файл | Тема | Идея сцены |
|---|---|---|
| `examples/study-project.svg` | Сложное изучение проекта | Книга — главный объект, ручка связана с заметками, папка поддерживает рабочий контекст, лампа остаётся дальше и не перетягивает фокус. |
| `examples/quiet-break.svg` | Тихая минута отдыха | Книга задаёт чтение, наушники поддерживают отдых, цветы добавляют спокойный природный акцент. |
| `examples/financial-planning.svg` | Серьёзная финансовая работа | Папка и кошелёк организуют финансовую тему, монета даёт конкретный смысл, ручка связана с записью, лампа подсвечивает рабочую зону. |

Откройте любой SVG в браузере или импортируйте в редактор. Исходные узлы каждого объекта остаются отдельными группами с `data-concept` и `data-role`.

Для интерактивной демонстрации запустите приложение, откройте `/`, добавьте объекты вручную либо используйте смысловой режим, затем попробуйте сменить формат, палитру, размер и видимость фоновых предметов. Для онлайн-подбора предварительно настройте профиль на `/ai`; без него ручной редактор остаётся доступен.
