# Архитектура Omega Illustrator

## Слои

1. **`OmegaIllustrator.Web`** — ASP.NET Core 10 и Blazor Interactive Server. Отвечает за редактор, каталог предметов, настройки AI и локальный HTTP-хост.
2. **`OmegaIllustrator.Core`** — доменные модели и правила смыслового плана, тем и проверки результата. При недоступности модели приложение использует локальный подбор.
3. **`Omega.AI.Gateway`** — отдельная библиотека в соседнем каталоге исходного архива. Единый контракт запросов, список моделей, проверка соединения и адаптеры провайдеров.
4. **`wwwroot/Assets`** — только публикуемые SVG, каталог, палитры и метаданные примеров. Исходный файл `.fig` и диагностические выгрузки не нужны работающему приложению.

## Поток смыслового подбора

```text
Тема и настройки сцены
        ↓
Формирование полного системного контракта + JSON-входа
        ↓
Выбранная модель через Omega.AI.Gateway
        ↓
Разбор JSON и проверка каталога, ролей, цветов и композиционных связей
        ↓
Локальный layout engine рассчитывает размеры и конечные координаты
        ↓
Редактор показывает сцену; пользователь может двигать объекты и менять слои
        ↓
SVG exporter встраивает исходные векторы, переименовывает внутренние ID,
применяет цвета и трансформации
```

Модель предлагает семантический план, но не возвращает произвольную SVG-разметку. Геометрия ассетов остаётся исходной. Контракт, матрица предметов, правила перекрытия и JSON-пример описаны в [COMPOSITION_MODEL.md](COMPOSITION_MODEL.md).

## Данные и секреты

Настройки выбранного профиля/модели и API-профили находятся вне `wwwroot` в `%LOCALAPPDATA%\OmegaIllustrator` либо в каталоге из `OMEGA_DATA_DIR`. Секреты защищаются ASP.NET Core Data Protection. При развёртывании на сервере следует использовать подходящее защищённое хранилище ключей и не открывать локальную конфигурационную страницу анонимным пользователям.

## Запуск

Готовый архив содержит self-contained публикацию Windows x64. Он слушает только loopback-адрес `127.0.0.1`; удалённое серверное развёртывание в этот пакет не включено.
