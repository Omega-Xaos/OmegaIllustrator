# SVG-каталог

## Состав

Рабочая библиотека находится в `src/OmegaIllustrator.Web/wwwroot/Assets`:

- 10 концептов: книга, телефон, пазл, монета, наушники, лампа, цветы, кошелёк, папка и ручка;
- для каждого концепта — размеры `S` и `L` и роли `main` и `background`;
- итого 40 SVG-вариантов;
- `catalog.json` связывает идентификатор, исходный node ID, вариант, теги, `viewBox`, цветовые роли и путь к файлу;
- `Palettes/` содержит три палитры, `Examples/catalog.json` — метаданные 18 примеров из исходного Figma-документа.

Роль `background` — отдельный исходный SVG-вариант для второго плана; приложение не делает его прозрачным изменением opacity. Размеры `S/L` выбирают варианты исходной детализации, а конечное масштабирование сохраняет пропорции.

## Цвета

Цвета предметов заменяются через семантические слоты `objectOnly.accent1..3`, `neutral.outline` и `neutral.white`. Три фоновые схемы заданы в `Palettes/catalog.json` и `palette-1.json` … `palette-3.json`. Чёрный контур и нейтральные элементы не перекрашиваются как акцент.

## Проверка происхождения и структуры

Исходные векторы получены из локального `.fig` инструментом `tools/FigmaAssetExtractor`; runtime использует только извлечённые SVG. В этой сборке проведена XML-проверка всех 40 файлов: корневой элемент `svg` корректен, узлов `<image>`, скриптов, `foreignObject` и внешних ссылок не обнаружено. Это проверка структуры и самодостаточности, а не попиксельное сравнение каждой версии с Figma.

Для повторного исследования включены файл `Тестовое _ иллюстрации.fig`, манифест, исходник извлекателя и сведения о лицензии зависимости. Диагностические превью и старые выходные каталоги в пакет сдачи не включены.
